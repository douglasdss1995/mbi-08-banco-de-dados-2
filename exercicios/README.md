# Exercícios da turma

Banco de Dados 2 · Turma MBI-08

Uma pasta para cada exercício. Em cada pasta:

- `exercicio-NN.md`: o enunciado;
- os arquivos que o exercício usa (referências e os scripts do banco da Loja Virtual).

Para montar o banco, rode na ordem: `01_ddl.sql`, `02_carga.sql`, `10_expansao_ddl.sql`, `11_expansao_carga.sql`. Para repetir, comece sempre pelo `01_ddl.sql`.
